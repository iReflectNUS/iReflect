# Version A：仅修改 feedback suggestions

日期：2026-10-14。按用户最新要求，保留原本评分特性，只修改 version A 的建议和意见生成规则。

## 实际修改

唯一业务代码修改是 `backend/pigeonhole/feedback/logic.py` 中 `askChatGPTOriginal` 的 Step 2 提示词。现有分组仍为偶数账号 BASIC/version A、奇数账号 ADVANCED/version B。没有修改分组或 version B。

原始 Step 1 前缀及六项 rubric 文字保持逐字一致；Step 3 汇总总分的指令保持逐字一致。保留每维 0–2 分、总分计算、评分依据说明、原始模型 `gpt-4o`、temperature 0.1、单次模型调用、原有答案输入和返回值处理。没有增加新模型、重评分、数据库字段、迁移、审批步骤或前端交互。

新增建议规则：

1. 先通读全文，检查建议要求的内容是否已经出现，识别同义表达和分散在其他段落的证据。
2. 区分「已经涉及但关系不清楚」与「完全没有」，避免错误声称学生未讨论某项内容。
3. 总共给出零至两条优先建议，每条指出具体缺口和可执行动作，避免笼统要求「更深入」或单纯增加篇幅。
4. 不因某个维度未满分就强制给出建议；每个维度的分数及其依据说明仍须保留。
5. 不虚构情绪、经历、因果解释、前题类别或同伴反馈，不要求重复已有计划、例子和解释。
6. 不把各评分维度都转化成额外写作任务；在实际可判断的范围内允许停止修改。

使用的技术包括：证据约束、反证检查、必要性判断、建议与评分规则分离、最小充分反馈及上下文边界。它们是对既有单次提示词的建议部分改写，没有采用此前 G5+R2 的双调用架构。
