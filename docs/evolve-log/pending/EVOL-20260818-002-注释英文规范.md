# EVOL-20260818-002 — 代码注释一律使用英文

- **状态**: PENDING（待 Owner 审阅）
- **来源**: user-correction（CORR-001）+ x-flow:archive
- **日期**: 2026-08-18
- **目标规则**: `.codebuddy/rules/code-quality-standards.mdc` §3 注释规范
- **优先级**: high

## 问题描述

用户明确纠正：本项目为国际化科研项目，代码注释（含 `@changelog` 表、docstring、行内注释）必须全英文，禁止中英混杂。本次需求 IMPL 阶段曾出现中文注释被用户纠正后返工。

## 现状

`code-quality-standards.mdc` §3 有"注释应解释为什么而非做什么"等一般要求，但**未明确注释语言为英文**，导致 AI 生成代码时混用中文注释。

## 建议规则

在注释规范 §3.2 中新增：

```
注释语言：所有代码注释（含 @changelog 表、docstring、行内注释）一律使用英文。
本项目为国际化科研项目，禁止中英混杂。
```

## 证据

- 记忆 `CORR-001`（evolve/corrections.md，user-correction，2026-08-18）
- `06_impl_log.md` 自检项 #1（注释英文返工）

## 应用场景

编写或修改任何代码（Python / TypeScript / JS 等）时生效。
