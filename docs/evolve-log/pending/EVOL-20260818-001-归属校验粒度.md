# EVOL-20260818-001 — 归属校验需细化到资源所有者级

- **状态**: PENDING（待 Owner 审阅）

- **优先级**: high

## 问题描述

新增的 AI 反馈版本上报接口中，写操作权限校验仅到"课程成员"级（`check_course_membership`），未校验到 submission 所有者级。E2E 实测：课程成员可在他人 **INDIVIDUAL** submission 下成功上报反馈版本（OBS-001）。

## 现状

- 课程成员级校验保证"是本课程的人"，但保证不了"是这条提交的主人"
- GROUP 协作场景正确（组内成员可操作）
- INDIVIDUAL 场景存在数据错位风险

## 建议规则

在安全基线中新增：

```
资源级归属校验：若写接口操作的资源存在 creator/owner 字段，
在课程/项目成员级校验之上，需叠加资源所有者级校验
（INDIVIDUAL 资源：creator == requester；GROUP 资源：组成员均可）。
```

## 证据

- `09_test_report.md` OBS-001（E2E 越权上报实测）
- 记忆 `EV-001`（evolve/corrections.md）

## 应用场景

任何以"课程/项目成员"为粒度的写接口，若资源本身有 owner，需追加资源所有者校验。
