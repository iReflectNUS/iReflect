# Playtest AI 评分展示控制（教师端开关）

## 1. 背景与目标

当前 Playtest 反馈中 AI 生成的评分（分数）与学生端文字建议**一并展示**，学生可以看到全部数字评分。

教学实践中，教师可能希望：
- 在**探索性写作/初稿**阶段只给学生**文字建议**，避免分数带来的压力或导向性；
- 在**定稿/评估**阶段再开放分数。

因此需要在**教师端**提供课程级开关，控制学生端是否展示 AI 分数。

**目标**：教师可在课程设置页一键控制「分数+建议」或「仅建议」两种展示模式，默认仅建议，且变更对所有（含历史）反馈立即生效。

## 2. 用户角色

| 角色 | 行为 |
|------|------|
| 教师/教育者（EDUCATOR） | 在课程设置页配置分数展示开关 |
| 学生（STANDARD） | 在反馈查看界面按配置看到「分数+建议」或「仅建议」 |
| 管理员（ADMIN） | 同教师，可配置（权限沿用现有 check_account_access 体系） |

## 3. 功能需求

### 3.1 课程级展示模式配置

- **描述**: 教师可在课程设置页设置该课程 Playtest 反馈的展示模式。
- **用户故事**: 作为教师，我希望在课程设置页选择"分数+建议"或"仅建议"，以便控制学生看到的反馈内容。
- **优先级**: P0
- **验收标准**:
  - [ ] 课程设置页出现「AI 评分展示」开关，提供两个选项：分数+建议 / 仅建议
  - [ ] 默认值为「仅建议」（新建课程即生效，不额外操作）
  - [ ] 教师保存后配置持久化，刷新/重新登录后仍生效
  - [ ] 非教师角色无法修改该配置（403 或 UI 不可见）

### 3.2 学生端按配置渲染反馈

- **描述**: 学生查看 Playtest 反馈时，根据课程配置决定是否显示分数。
- **用户故事**: 作为学生，我查看反馈时只看到教师允许我看到的（分数+建议，或仅建议）。
- **优先级**: P0
- **验收标准**:
  - [ ] 配置为「分数+建议」时，学生端展示分数与文字建议（与现状一致）
  - [ ] 配置为「仅建议」时，学生端**不显示任何数字分数**（总分与分维度分数全部隐藏），仅显示 AI 文字反馈
  - [ ] 仅建议模式下，页面不出现分数占位符/空值显示
  - [ ] 教师修改配置后，学生端**无需刷新旧数据**，下一次拉取即按新配置渲染（历史反馈同样生效）

### 3.3 后端强制过滤（安全）[AI 推断]

- **描述**: 分数可见性由后端接口强制控制，而非仅前端隐藏，防止学生绕过 UI 直接读取分数。
- **用户故事**: 作为系统，我保证学生通过 API 只能拿到被允许的数据。
- **优先级**: P0
- **验收标准**:
  - [ ] 学生角色的反馈查询/上报响应中，当配置为「仅建议」时**不含** score_json 分数数据（字段置空或裁剪）
  - [ ] 教师/管理员角色的响应不受该配置影响，始终含完整分数
  - [ ] E2E 实测：仅建议模式下，学生 token 拉取反馈响应中无分数；切回分数+建议后，同接口出现分数

## 4. 非功能需求

- **安全**: 分数裁剪必须在后端执行（服务端渲染/序列化层），禁止仅依赖前端样式隐藏；参考记忆 EV-001（课程成员级 ≠ 资源所有者级）的越权风险，本需求的可见性控制同理需要后端兜底。
- **兼容性**: 现有「分数+建议」为行为变更默认值（新默认「仅建议」），旧课程创建时即采用新默认，无需数据迁移。
- **性能**: 配置读取走课程维度的单次查询，反馈列表接口不因配置增加 N+1 查询。

## 5. 约束与假设

- **假设**: 展示模式是**课程级全局**开关，不细分到提交/反馈记录（用户已确认）。
- **假设**: 只提供「分数+建议 / 仅建议」两种模式，不提供「仅分数」（用户已确认）。
- **假设**: 「仅建议」时隐藏全部数字分数（含总分与分维度），保留全部文字建议（用户已确认）。
- **约束**: 配置变更对历史反馈**立即生效**（用户已确认），因此实现上应为"读取时按当前配置动态裁剪"，而非"生成时固化"。
- **约束**: 沿用现有权限体系（check_account_access + 课程成员校验），不引入新权限模型。

## 6. 影响范围

- **涉及服务**: backend（Django/DRF）、frontend（Next.js）
- **涉及模块**:
  - 后端：课程模型/序列化器（新增展示模式字段或配置存储）、feedback 相关接口（响应按角色裁剪分数）、课程设置相关接口（读写配置）
  - 前端：课程设置页（新增开关）、playtest 反馈渲染组件（按配置渲染分数区）、反馈 API 类型
- **数据库变更**: 是（课程配置字段或独立配置表，具体由 DESIGN 阶段确定）

- **LT-012**（隔离 E2E）: 验证分数裁剪建议沿用独立 sqlite + 真实 HTTP 的 E2E 方法
